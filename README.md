# ZBCgifs – Manim-Animationen für Biologie und Chemie

Minimalistische, frei zugängliche Sammlung von transparenten Manim-Animationen (`.gif`) für den Biologie- und Chemieunterricht am bayerischen Gymnasium (LehrplanPLUS).

**Website:** https://herrzo.github.io/zbcgifs/

## Funktionen für Lehrkräfte
- **Heller/weißer Hintergrund:** Optimiert für das direkte Einfügen in PowerPoint-Präsentationen.
- **LehrplanPLUS-Filter:** Schnelle Auswahl über die Header-Menüs **Biologie** (`NUT5`, `NUT6`, `BIO8`, `BIO9`, `BIO10`, `BIO12`, `BIO13`) und **Chemie** (`CHEM9`, `CHEM10`, `CHEM12`, `CHEM13` – dargestellt für das sprachliche und wirtschaftswissenschaftliche Gymnasium SG/WSG).
- **Sofortsuche:** Durchsucht Titel, sichtbare Schlagworte, versteckte Synonyme/Summenformeln und Lernbereiche.
- **Mehrschrittige Prozesse:** Zusammengehörige Schritte `(1)`, `(2)`, `(3)` werden automatisch verknüpft und können gesammelt heruntergeladen werden.
- **One-Click PowerPoint-Workflow:** Direktes Herunterladen als `.gif` oder Kopieren für PowerPoint.
